# E-Commerce Project

An eCommerce project built with HTML, CSS, Bootstrap, MongoDB, and Node.js.

## Overview

Welcome to ZFashion! This website is your one-stop destination for all your fashion needs. Built with HTML, CSS, Bootstrap, MongoDB, and Node.js, our clothing store brings you a seamless and enjoyable shopping experience.

## Features

- User-friendly interface for browsing products.
- Product catalog with detailed information.
- Shopping cart functionality.
- User authentication and authorization.
- Secure checkout process.
- Admin panel for managing products, orders, and users.
- Payment gateway using Razorpay.
- Review and Rating
- Coupons and offers
- Wallet

## Technologies Used

- HTML: Markup language for creating web pages.
- CSS: Style sheet language for designing the layout of web pages.
- Bootstrap: Front-end framework for building responsive and mobile-first web projects.
- MongoDB: NoSQL database for storing product and user information.
- Node.js: JavaScript runtime for server-side development.
